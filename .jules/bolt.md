## 2026-07-06 - Date String Aggregation in JS timezone issues\n**Learning:** When fixing N+1 loop performance issues by pulling down big blocks of data and doing local aggregation, converting to `.toISOString().split('T')[0]` breaks timezone boundaries. Using `.getTime()` alongside proper local time start and end of day boundaries is much safer.\n**Action:** Use time-boundaries via `.getTime()` to check if elements belong to a date range.
